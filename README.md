# The Wedding Content Guide

An independent editorial site explaining the **wedding content creator** role: what it is, real 2026 rates, an interactive price calculator, and a free contract template.

## Pages

- `index.html` — What is a wedding content creator? (main hub, calculator + rate tables + FAQ)
- `wedding-content-creator-contract-template.html` — free 12-clause agreement template (email lead magnet + direct `.docx` download)
- `assets/` — optimized WebP illustrations and the downloadable contract (`.docx`)

## Stack

Plain static HTML/CSS/JS. No build step, no framework. Deployable as-is on GitHub Pages, Cloudflare Pages, or Netlify.

- Fonts: Cormorant Garamond + Jost (Google Fonts)
- Structured data: Article + FAQPage JSON-LD
- No tracking in this repository yet

## Legal note

The contract template is general information, **not legal advice**. Have a licensed local lawyer review it before use.
